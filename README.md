# シンプルタイマー

時間を選んで、スタート・ストップ・リセットができるシンプルなタイマーです。

このアプリは、Git・GitHubのチュートリアルを通して作成しました。 学ぶことを目的にしています。

## 機能

- 1分、3分、5分、10分、25分、1時間から時間を選択
- タイマーのスタート
- タイマーの一時停止
- タイマーのリセット

## 使い方

1. `timer.html` をブラウザで開きます。
2. お好みの時間を選びます。
3. 「スタート」を押すとカウントダウンが始まります。
4. 必要に応じて「ストップ」や「リセット」を使います。

## 使用している技術

- CSS
- JavaScript
